# Issue Tracker Configuration

- **Tracker**: GitHub Issues
- **CLI**: `gh`
- **PRs as request surface**: false

## Usage Rules

When reading or creating issues:
- Use `gh issue list` and `gh issue view <number>` to read issues.
- Use `gh issue create --title "<title>" --body "<body>"` to create issues.
- Do not treat pull requests as issue requests unless explicitly requested.
